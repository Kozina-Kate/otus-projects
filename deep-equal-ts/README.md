# Deep Equal TypeScript

Типизированная реализация глубокого сравнения значений на основе классов-компараторов.

Поддерживаются примитивы, массивы, обычные объекты, `Date`, `RegExp`, `Map` и
циклические ссылки. Движок можно расширять собственными компараторами.

## Установка и запуск

```bash
npm install
npm test
```

Проверить только компиляцию:

```bash
npm run build
```
