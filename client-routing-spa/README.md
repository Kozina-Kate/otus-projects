# Порядок · клиентский роутинг и мини-SPA

Небольшой менеджер задач на React и TypeScript: три страницы, единый глобальный
стор, формы, поиск и сохранение данных на устройстве. Интерфейс адаптирован под
телефон и поддерживает светлую и тёмную темы.

## Запуск

Нужен Node.js 22.22.2+, 24.15.0+ или 26+. Проверено на Node.js 26.10.0.
Из корня репозитория:

```bash
cd client-routing-spa
npm ci
npm run dev
```

Откройте адрес из терминала, по умолчанию http://127.0.0.1:5173.

```bash
npm test          # тесты стора и пользовательских сценариев
npm run build    # проверка TypeScript и production-сборка в dist/
npm run preview  # локальный просмотр production-сборки
```

## Стек

- React + TypeScript — интерфейс и типы данных.
- Vite — сервер разработки и сборка.
- React Router, декларативный режим с BrowserRouter — клиентские маршруты.
- Zustand + persist — общий стор и сохранение его части в localStorage.
- CSS — адаптивная вёрстка, темы и видимый фокус для клавиатуры.
- Lucide React — иконки.
- Vitest, Testing Library, jsdom — тесты.

Node.js нужен для инструментов разработки. Приложение выполняется в браузере;
бэкенд и авторизация не требуются. Шрифты загружаются из Google Fonts; без сети
используется системный sans-serif.

## Маршруты

| Адрес | Страница | Использование общего состояния |
| --- | --- | --- |
| `/` | Обзор | Имя, статистика и последние задачи |
| `/tasks` | Мои задачи | Форма, список, фильтры, выполнение и удаление |
| `/settings` | Настройки | Имя, тема и фильтр по умолчанию |
| `*` | Не найдено | Ссылка возврата на обзор |

Навигация использует Link/NavLink: документ при переходах не перезагружается.
Кнопки браузера «Назад» и «Вперёд» поддерживаются BrowserRouter.

## Общее состояние

`src/store.ts` содержит задачи, настройки, текущий фильтр и черновик новой задачи,
а также действия добавления, переключения статуса, удаления и изменения настроек.
Статистика вычисляется из задач и отдельно не сохраняется.

Форма задачи управляется через стор; после отправки задача появляется в списке,
а статистика обзора и счётчик навигации обновляются автоматически. Черновик
сохраняется при переходе между страницами, но сбрасывается при перезагрузке.
Пустые названия и названия длиннее 120 символов не принимаются. Имя сохраняется
кнопкой формы; тема и фильтр по умолчанию применяются сразу.

В localStorage под ключом `poryadok-app` сохраняются **только задачи и настройки**.
При открытии приложения текущий фильтр инициализируется выбранным фильтром по
умолчанию. Поиск, черновик и сообщения формы не сохраняются. Восстановленные
данные проходят проверку формы и типов; повреждённый JSON не мешает запуску.
Хранилище относится к текущему браузеру и origin. Очистка данных браузера удаляет
задачи; синхронизации между устройствами нет.

## Проверка задания

1. Открыть `/tasks`, отправить пустую форму — появится ошибка.
2. Добавить задачу, завершить её и перейти на обзор — обновятся счётчики и прогресс.
3. Вернуться к задачам, проверить фильтры и поиск, удалить задачу.
4. На `/settings` изменить имя и тему; перейти на обзор — применятся оба изменения.
5. Выбрать фильтр по умолчанию, обновить страницу — задачи и настройки сохранятся.
6. Проверить переходы назад/вперёд и прямое открытие `/tasks`, `/settings`, неизвестного адреса.

Для размещения на хостинге с BrowserRouter нужно настроить возврат `index.html`
на клиентские пути (`/tasks`, `/settings` и другие). Серверы Vite dev/preview
обрабатывают это локально. Простой статический хостинг без fallback при обновлении
вложенного адреса вернёт серверную 404. Размещение в подпапке дополнительно требует
настроить Vite `base` и BrowserRouter `basename`.

## Структура

```text
src/
  main.tsx       # подключение BrowserRouter
  App.tsx        # общий layout, маршруты, страницы и компоненты
  store.ts       # состояние, действия, persist и проверка данных
  styles.css     # оформление и адаптивность
  App.test.tsx   # пользовательские сценарии
  store.test.ts  # действия и восстановление состояния
  test/setup.ts  # окружение тестов
```
